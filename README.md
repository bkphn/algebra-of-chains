# Algebra of Chains (pol. _Algebra łańcuchów_)

This repository contains the formalization of my original mathematical framework called **Algebra of Chains**. It shifts the focus from fractions as representations of rational numbers to chains as primary algebraic objects.

## Current State
* `Algebra_lancuchow.pdf` - The foundational paper introducing the spaces (Zaremba), unary/binary operators, and numerator/denominator functions (in Polish).
* *A full Markdown translation with LaTeX equations is currently in progress.*

## Core Concepts
The framework allows for structural manipulation of continued fractions (including improper chains containing zeros) without falling back to matrix-based arithmetic (like Gosper's algorithm) or rational evaluation $\mathbb{Q}$.
